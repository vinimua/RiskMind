# 缺失率口径

比较前核对缺失值定义、统计单位、窗口、字段版本和样本筛选。不要混用客户数、申请数和记录数。

## 结果分支

- 有样本且分子为零：只说明按该口径没有观察到缺失，不证明所有字段或生产数据完整。
- 零样本：先查数据集和窗口覆盖；缺失率没有可用分母，不能解释为零。
- 缺失率变化：同时查看分子与分母，避免把样本量变化误写为缺失记录增多。
- 当前窗口和基准口径不一致：先核对版本或筛选条件，不直接计算相对变化或下结论。
- 工具失败或拒绝：缺失率未知，不能当成零样本或零缺失。

当前 CSV 工具使用左闭右开时间窗口。统计结果仅覆盖指定离线数据集，不直接证明线上链路故障。
需要按渠道或版本分组而工具不支持时，明确保留分组证据缺口，不从总体统计推出局部原因。
