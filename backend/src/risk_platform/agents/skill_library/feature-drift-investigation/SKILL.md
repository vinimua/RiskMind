# 特征漂移调查

## 必要输入

明确目标特征、特征版本、当前窗口、参考窗口及样本范围；解释告警还需指标来源、计算口径与可信阈值配置。
优先核对案件中已有指标与来源。缺少比较基准或版本时先安排查证，不自行选取有利的参考窗口。

## 调查步骤

1. 区分需要调查的是分布变化、缺失值变化还是性能变化，避免用一个指标回答不同问题。
2. 比较前核对特征定义、样本筛选和两个窗口。版本不同或样本口径不明时，先解决可比性问题。
3. 解释 PSI 或安排 PSI 指标查询前，按需读取 `references/psi.md`。
4. 有对应事实工具时查询当前与参考分布、指标及来源；只有知识工具时检索定义和历史线索，明确当前分布仍未知。
5. 先描述已观察到的差异，再安排有证据指向的数据质量、特征版本或客群变化补查。不能因单一漂移指标直接指定根因。
6. 用户还询问性能影响时，将标签成熟度和实际性能指标列为后续问题，不用 PSI 代替 KS 或 AUC。

## 工具使用

只根据当前真实可用能力生成任务。现有 CSV 工具能提供样本量、缺失率和坏标签占比，不能计算 PSI 或完整特征分布。
没有对应指标工具时，不生成声称可由 CSV 工具计算 PSI 的任务；可检索计算口径或历史案例，并保留事实工具缺口。

## 输出要求

沿用平台契约。任务明确目标特征、比较窗口和需要的事实，引用实际读取的方法文件。
发现应说明变化依据、适用样本和可比性限制；未获得指标时写明缺什么，不将告警描述或历史案例重写成新测量结果。

## 失败与边界

- 无参考分布、零样本、计算失败或版本不可比时，不宣称漂移已证实或已经消失。
- 无可信阈值配置时，只描述实际指标，不自定生产分级或处置门槛。
- 分布差异不单独证明数据错误、性能下降或因果关系。本文件不是案件证据，也不能触发发布、规则修改或回滚。
