# PSI 调查注意事项

解释 PSI 前确认指标对应的特征、两个窗口、样本筛选、分箱边界、缺失值处理、零频平滑和特征版本。
使用同一比较规则核查指标；不同分箱或样本口径算出的 PSI 不能直接作为趋势比较。

## 结果分支

- 只有 PSI 告警：核对来源和计算口径，不能把告警原文当成一次新的指标核实。
- 有实际 PSI 但没有可信阈值：描述数值及比较范围，不擅自划分生产风险等级。
- 某窗口零样本、空分箱处理不明或版本不同：保留可比性问题，不直接宣布漂移。
- 工具缺失、失败或拒绝：指标尚未取得；不能由知识检索正文或模型估算补齐。

PSI 描述分布差异，不单独证明预测性能下降、数据错误或因果关系；也不能定位差异由何种业务变化造成。
本文件不提供通用生产阈值或可执行计算脚本。
