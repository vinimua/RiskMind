# 标签成熟度

核对标签事件定义、表现期起点、表现期长度、观察截止时间、回传延迟和标签来源。
口径说明只能告诉我们如何判断成熟；当前样本是否满足条件仍需真实数据或权威状态证明。

## 结果分支

- 成熟状态未知：先安排口径和状态核查，不根据记录非空、标签已有值或知识文档推断已成熟。
- 已知未成熟：当前观察到的好坏标签比例不能代表最终表现，性能判断保持 INCONCLUSIVE。
- 仅部分样本成熟：确认成熟样本选择规则和覆盖范围，不将子集评价直接推广到全部样本。
- 已有成熟事实：继续核对模型版本、样本范围和评价口径；成熟本身不保证指标可比或计算正确。
- 无状态工具或查询失败：明确成熟度证据缺口，不能将缺失状态当成通过。

不在 Skill 中写死表现期天数或回传延迟；以当前可信配置及适用版本为准。
