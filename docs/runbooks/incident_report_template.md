# 模板使用约定

1. 本模板用于 `INCIDENT_REPORT` 类型知识文档。
2. “调查过程”允许根据实际 Case 自由增删检查项，不要求所有 Case 使用相同检查清单。
3. 历史 Case 的根因和调查结论只能作为后续调查线索，不能直接作为当前异常事实。
4. 支持证据、排除项和最终根因应尽量分开记录。
5. 若证据不足，应明确记录未确认，不应强行给出根因。
6. 后续 Knowledge Compiler / Chunking 应保留章节路径，例如：
   - `调查过程 / 关键发现`
   - `根因与证据 / 支持证据与排除项`
   - `经验沉淀 / 可复用经验`
